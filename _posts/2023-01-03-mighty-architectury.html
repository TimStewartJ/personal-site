The Mighty Architectury

An experimental Forge and Fabric compatibility port of The Mighty Architect.

What it is

The Mighty Architectury is a port of simibubi's The Mighty Architect to an Architectury-based project. The goal was to make the building-design mod work across Forge and Fabric using a shared codebase.

Why it was interesting

Minecraft modding has a lot of moving parts: loaders, mappings, shared abstractions, game-version drift, and compatibility expectations from players. This project was a useful exercise in adapting an existing mod into a cross-loader architecture instead of starting from scratch.

Current State

This is experimental. Some things may still be broken, but I like keeping it visible because it represents a different kind of software work than the web apps and small utilities on this page.

Stack

Java, Minecraft modding, Architectury, Forge, and Fabric.
