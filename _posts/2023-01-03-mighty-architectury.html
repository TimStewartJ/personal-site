The Mighty Architectury

A maintained port of The Mighty Architect for Fabric, NeoForge, and Forge.

What it is

The Mighty Architectury is a port of simibubi's The Mighty Architect, a Minecraft mod for designing elaborate buildings within a minute. It runs on Fabric, NeoForge, and Forge for Minecraft 1.19.4 to 26.3, and it has been downloaded more than 50,000 times on Modrinth.

Why it was interesting

Minecraft modding has a lot of moving parts: loaders, mappings, shared abstractions, game-version drift, and compatibility expectations from players. It started in 2023 as an Architectury-based port, which is where the name comes from. It no longer uses a third-party multiloader framework: each loader is built with its own official toolkit, so the mod needs nothing at runtime beyond the loader itself, plus Fabric API on Fabric. One source tree builds every supported Minecraft version.

Current State

Maintained. Every jar is tested the way it ships: the same client test harness runs against the packaged mod on every supported version and loader, alongside a dedicated-server test and a JUnit suite. Bugs still happen, and reports on GitHub are welcome.

Stack

Java, Gradle with Stonecutter, Fabric, NeoForge, and Forge.
