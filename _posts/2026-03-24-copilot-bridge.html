Copilot Bridge

A local, task-centric AI workspace built on the GitHub Copilot SDK.

The Problem

AI tools are usually chat-first. That is useful for quick answers, but real work has context: tasks, notes, schedules, docs, prior sessions, linked pull requests, and state that should survive the tab closing.

The Solution

Copilot Bridge is my attempt to make AI feel less like a disconnected chat box and more like a durable workspace. It keeps conversations next to the task they belong to, gives the agent tools for the surrounding workspace, and treats personal automation as something that can be shaped over time.

What It Does

  • Persistent task-scoped Copilot sessions with streaming responses and tool call visibility
  • Tasks, groups, tags, notes, checklists, linked work, and pull request context
  • A markdown knowledge base with wikilinks and database-style collections
  • Scheduled prompts for recurring reviews, reminders, and automated workflows
  • Browser, web, docs, task, GitHub, Linear, and optional desktop automation tools
  • Launcher-managed restart, update, staging preview, and rollback flows so the app can help improve itself

Why It Matters To Me

The project is intentionally personal. It is not trying to be a generic SaaS product; it is a way to explore what happens when an AI workspace is built around one person's real workflows instead of an abstract average user.

Stack

TypeScript, React, Express, SQLite, Vite, GitHub Copilot SDK, and a local-first markdown/docs workflow.
